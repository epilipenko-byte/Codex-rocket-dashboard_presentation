# Codex навыки оформления дашборда

Этот файл хранит практики оформления, которые были применены или должны применяться в дашборде.

## Общий стиль

- Дашборд должен открываться как рабочий инструмент, а не лендинг.
- Интерфейс плотный, финансовый, сканируемый.
- Основной акцент: вкладки, KPI, графики, таблицы, выводы.
- Фон может быть атмосферным, но не должен мешать чтению.

## Цвет и прозрачность

- Темная основа.
- Прозрачные панели, чтобы трава была видна мягко.
- Текст и цифры всегда должны иметь приоритет над декоративностью.
- Красный использовать для ROCKET/рисков/критики.
- Cyan/green использовать для live-статусов и положительных сигналов.

## Фон grass_bg.html

- iframe должен быть нижним слоем: `z-index:-1`.
- UI должен быть выше: `z-index:2`.
- Фон не должен перекрывать форму входа и вкладки.
- Вид травы: слегка сверху, не сбоку.
- Поле должно заполнять экран, но не вылезать за него.

## Вкладки и навигация

- Все 13 вкладок должны быть видны/доступны.
- Вкладки должны быть горизонтальными, сканируемыми.
- Активная вкладка должна ясно выделяться.

## Графики

- Chart.js подходит для текущей версии.
- Графики строить по массивам данных, нормализованным из Google Sheets.
- Подписи месяцев должны идти в календарном порядке.
- Не привязывать показатели к позициям в таблицах.
- Расходы в графиках P&L должны отображаться как положительные суммы, даже если Google Sheets хранит их со знаком минус; маржинальность пересчитывать после нормализации знаков.

## Таблицы

- Для raw-таблиц использовать ограничение строк и аккуратный скролл.
- Если таблица содержит служебные строки, искать реальные заголовки по словам.
- Длинные тексты задач не обрезать до полной потери смысла.
- Для матричных листов вроде ЦКП использовать доменный маркер шапки (`Период`), а не первую строку с названием блока.

## Статусы

- Не показывать `DEMO — тестовые данные` в рабочей версии.
- Допустимые статусы:
  - `LIVE — Google Sheets`;
  - `КЭШ — Google Sheets`;
  - `РЕЗЕРВ — ждёт Google Sheets`.

## Как обновлять этот файл

Если новая доработка улучшила читаемость, скорость, надежность или визуальный стиль, добавить правило сюда.
