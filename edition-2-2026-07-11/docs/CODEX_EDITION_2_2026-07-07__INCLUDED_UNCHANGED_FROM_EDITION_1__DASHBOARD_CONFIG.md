# Dashboard Config

Главная управляющая таблица:

https://docs.google.com/spreadsheets/d/1EKR-czK1UvXZDIJUe5MLb70yZXyEMe1VIYTx15UOY3E

## Роль

Dashboard Config должен управлять тем, какие источники данных читаются, какие вкладки видимы, какие листы участвуют в анализе, какие правила и примечания подключаются к дашборду.

## Ожидаемые листы по ТЗ

- `Reports` — перечень отчетов/источников.
- `Notes` — примечания к графикам.
- `AI Analysis` — результаты AI-анализа.
- `Threshold Rules` — пороговые правила.
- `Assumptions` — допущения.

## Важный алгоритм

Дашборд не должен привязываться к фиксированным строкам и столбцам. Apps Script должен:

1. Читать `Reports`.
2. Открывать каждый видимый источник.
3. Находить месяцы и показатели по названиям.
4. Нормализовать названия: регистр, пробелы, пунктуация, `ё/е`.
5. Допускать небольшие опечатки.
6. Использовать порог похожести 72%.
7. Отдавать единый JSON для фронта.

## Известные особенности

- В `tasks_data` первые строки могут быть служебными фильтрами. Реальная строка заголовков находится ниже. Фронт должен искать ее по словам `Задача`, `Ответственный`, `Дата план`, `Статус`, а не брать первую строку.
- В источниках могут добавляться месяцы после мая. Период должен расширяться автоматически.
- Если Google Apps Script отвечает медленно, фронт не должен показывать публичный статус `DEMO`; допустимы статусы `LIVE`, `КЭШ`, `РЕЗЕРВ`.
