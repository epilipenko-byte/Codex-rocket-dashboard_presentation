# CODEX_EDITION_III_2026-07-15 — protocol changes

Этот протокол фиксирует изменения Edition III относительно Edition II.

## Принятые решения

1. ЦКП показываются карточками “один ЦКП — таблица критериев — диаграмма справа — заметки докладчика”, но диаграмма ограничена размером правого блока.
2. ОПиУ показывается одной раскрываемой исходной таблицей вместо двух разных таблиц.
3. В ОПиУ верхний ряд KPI означает выбранный период, второй ряд — последний месяц выбранного периода.
4. P&L waterfall не используется в Edition III; вместо него показываются расходы по группам и маржинальность на фоне выручки.
5. ДДС показывает Total NCF на фоне поступлений и выбытий, а выбытия в обзорной диаграмме отображаются вверх как величина расхода.
6. В проектах Core восстанавливается из общей выручки, если proxy вернул Core нулём, чтобы легенда и диаграмма не расходились.
7. В балансе donut долговой структуры заменён на один показатель процентного долга, потому что donut с одной категорией не несёт аналитической ценности.
8. Все раскрываемые таблицы должны визуально следовать образцу ДДС: закреплённый первый столбец, мягкие выделения главных строк, числовые значения справа.

## Требования к proxy / Dashboard Config

- Источник листа должен определяться по `sheet_name` из Dashboard Config.
- Если в файле есть русский и английский одноимённые листы, а в Dashboard Config указан русский лист, proxy должен брать русский лист.
- Для `aff_buyback` proxy должен вернуть массив `aff_buyback_data`.
- Для ОПиУ proxy должен возвращать `pnl_data` именно с листа, указанного в Dashboard Config.

## Нормативы

Если норматив отсутствует в Dashboard Config, фронт показывает `*`. Это означает: норматив надо добавить в Dashboard Config, а не зашивать в код.
